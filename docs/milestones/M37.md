# M37: new data scopes and derivatives (explore)

**Status:** proposed; agents start M37 only after the owner merges it and
after earlier milestone files' agent tasks, unless the owner reorders.

**Depends on:** M28 (P01: M28.3 and M28.22–M28.27, F04 live order truth,
before any DEX venue work). M29 (M29.2, F26 coverage manifest and dataset
manifests, which every new dataset here must carry). M31 (M31.7, the
approved web history fetch, which sets the egress pattern). M37.1 and M37.2
gate every agent task except M37.3.

**Exit / gate:** the owner has recorded the perpetual product decision and
the data-rights decision. If both allow it, one venue's funding history is
read with correct units into a labelled dataset and shown read-only, and
Kraken pair tradability is recorded going forward. Otherwise M37 closes with
only the docs-only funding evaluation. The product stays spot long-only
unless the owner says otherwise.

Rules for every task are in `AGENTS.md`. Agents skip `[owner]` tasks.
`PAPER_ONLY_RELEASE` stays True. Tests use fake transports. Every new host is
listed in `docs/telemetry.md` before it is contacted. No shorting, leverage,
margin or perpetual orders (M15 out-of-scope stands). Keys and any wallet
key stay in the OS keychain (PARKING line 12). Backtests and scenarios are
never presented as market performance or predictions.

**Decisions adopted from the approved roadmap:**

- Decision 17: stay spot-only for V1. Before the perpetual decision, at most
  the docs-only funding evaluation (M37.3) proceeds.
- Decision 19: the only approved market-data egress is M31.7's web history
  fetch from hosts the scheduled tick already contacts. Archival candles,
  listing and delisting metadata, funding endpoints and other new market-data
  hosts need M37.2. Licensed metadata stays deferred.
- No new live venue here (PARKING line 16).

**Parallelism:** M37.3 first (no deps). M37.4 after M37.1, M37.2 and M37.3.
M37.5 after M37.4. M37.6 and M37.7 after M37.2.

## Explicitly out of M37

- Liquidation, collateral and margin what-if scenarios (F64): no task until
  M37.1 approves perpetuals and venue margin formulas are validated. A spot
  DCA cash-path what-if is a different feature and does not substitute.
- DEX perpetual venues and wallet signing (F65): no task until M37.1 and a
  wallet threat model. The Hyperliquid spot paper connector in
  `docs/venue-candidates.md` is venue breadth, not this feature.
- Sub-hour series, order-book or latency simulation (F28 beyond M37.7), and
  listing-history backfill (F27 beyond M37.6): each needs M37.2 and its own
  task.
- Funding or carry alerts, and any hedge or carry execution (F63 declined).
