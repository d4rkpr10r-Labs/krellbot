# M38: Krell and the agent control layer

**Status:** proposed. **Owner reorder (2026-11-27):** once the owner merges
this file, agents take M38's tasks before the rest of M29. M29.1, which M38.5
depends on, stays in M29 and goes first.

**Spec:** [design](../superpowers/specs/2026-11-27-krell-agent-control-layer-design.md).
**Plan** (interfaces and tests for every task):
[plan](../superpowers/plans/2026-11-27-krell-agent-control-layer.md). Read
both before starting a task. A task's interfaces in the plan are part of
the task.

**Depends on:** M28 (all agent tasks merged), M29.1 (run record and
`compute_run_id`).

**Exit / gate:** Any local MCP client can add Krellbot and draft, validate,
backtest, compare and paper-arm under the operator's limits. A user who
connects a model, by API key, OpenRouter sign-in or a custom
OpenAI-compatible or Anthropic-compatible endpoint, meets Krell. Krell asks
standard or advanced, guides them, and arms a paper run only after they
press Confirm. Every agent action and refusal shows in Operations → Agent
activity. No agent can arm live, touch keys, place or close an order, or
change a live strategy.

Rules for every task are in `AGENTS.md`. Agents skip `[owner]` tasks.
`PAPER_ONLY_RELEASE` stays True. Agents never choose orders, override risk,
arm live, read keys, close positions or change live strategies. The
loopback API keeps its authentication, session, CSRF, origin and host
checks. Every new route uses `_gate_get` or `_gate_state_change`. Tests use
fake AI transports, in-memory MCP sessions, the fake keyring and an isolated
home; CI makes no real provider calls. Nothing about agents or
conversations goes to `krellbot.dev`. Backtests are always labelled
simulated, and the UI draws that label from tool results, never from
model text. The CLI stays plumbing: `krellbot mcp` is a launcher entry
only.

**Decisions adopted (owner, 2026-11-27):**

- Agents build, Krellbot trades. Humans choose and arm every strategy.
  Krell confirms before heavy or state-changing work, and the confirm card
  is the human arming.
- External MCP agents may paper-arm within the operator's limits without
  Krellbot-side approval (their client asks per call). Pause, resume and
  disarm are off for them by default. This resolves M34.8.
- MCP SDK: the official `mcp` package, pinned `mcp==2.3.0`. This resolves
  M34.9.
- Providers: every major provider by API key, plus custom endpoints;
  sign-in for OpenRouter now and ChatGPT once M38.22 confirms eligibility.
  No Claude subscription credentials; Claude users use an API key or MCP.
  This resolves M34.10.
- Krell has her own tab and a side panel on every other screen. Her face
  appears only in the conversation.
- First run: the wizard's welcome step offers "Meet Krell (connect your
  AI)" as a secondary choice.
- This milestone replaces M34.5–M34.7; M31.5's policy editor moves to
  M38.10.

## Epic M38-A — Agent tool core

## Explicitly out of M38

- Remote MCP (ChatGPT connectors, claude.ai remote connectors) or any
  non-loopback listener beyond the M38.20 redirect.
- Claude Pro/Max subscription credentials in any form.
- Google sign-in for Gemini (needs a registered, verified Google Cloud
  client; API keys work now).
- Agents placing, closing or changing live orders or strategies.
- A Learn view, a Beginner/Power toggle, or a second app shell.
- API scopes for non-browser clients (M34.11 stays open).
